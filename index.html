Source Code Backend Google Apps Script (Code.gs)

Script Web App siap salin untuk menangani sinkronisasi soal aktif, pembuatan sheet otomatis (insertSheet), dan pencatatan nilai.

Panduan Praktis Pasang di Google Spreadsheet:
  1. Buka Spreadsheet Google → pilih menu Ekstensi > Apps Script.
  2. Hapus fungsi bawaan function myFunction() {} sampai editor kosong bersih.
  3. Klik tombol biru "Salin Kode Code.gs (Siap Paste)" di atas, lalu tempelkan (Ctrl+V) ke editor Apps Script.
  4. Pilih fungsi setupDatabaseSheets pada toolbar atas, lalu klik Jalankan (Run) untuk inisialisasi sheet otomatis.
  5. Klik tombol biru Deploy > New deployment → pilih jenis Web app → bagian Who has access pilih Anyone (Siapa saja) → klik Deploy.
  6. Salin Web App URL yang dihasilkan, lalu tempelkan ke form URL Master di atas dan klik Simpan Data & URL.

Download File HTML Mandiri (Self-Contained Deployment)

Fitur ini menyematkan seluruh konfigurasi terbaru (judul, durasi, KKM, token, 319 database siswa, jadwal, dan bank soal) langsung ke dalam file HTML. Anda dapat membagikan file ini ke seluruh siswa atau mengunggahnya ke hosting / GitHub Pages / server lokal tanpa perlu konfigurasi ulang.

Panduan Deployment Sekolah:
  1. Pastikan seluruh pengaturan dan data soal/siswa sudah disimpan.
  2. Klik tombol "Download HTML Terbaru" di bawah.
  3. File HTML baru akan otomatis terunduh dengan versi rilis yang diperbarui.
  4. Ganti file lama di hosting/server Anda dengan file baru tersebut.
Versi Rilis Saat Ini: v6.41

Sinkronisasi & Pemulihan Data Bawaan File HTML

Jika Anda membuka file HTML hasil unduhan dari GitHub Pages atau mengedit repository langsung di GitHub, namun browser Anda masih menampilkan data lama dari sesi sebelumnya (karena browser mengutamakan cache lokal perangkat), klik tombol di bawah untuk menyinkronkan seluruh database siswa, jadwal, dan bank soal langsung dari data yang tertanam di file HTML ini.
